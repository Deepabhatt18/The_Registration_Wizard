# 🚀 Registration Wizard (Multi-Step Form)

A responsive and user-friendly **Multi-Step Registration Form** built using React.
This project demonstrates **state management, form validation, and component-based architecture**.

---

## 📌 Features

* 🧩 Multi-step form (Step 1 → Step 2 → Step 3)
* 🔄 State lifting using React
* ✅ Real-time form validation
* 🔐 Password show/hide functionality
* 🚫 Disable Next button on invalid inputs
* 🔁 Data persistence across steps
* 🎯 Final review & submit functionality
* 🎉 Success screen after submission
